# Equalizer
Equalizer script detects all player matches generated by Scrapaer and applies Equalizer formulas to get the current APA skill level of each historical match and outputs to CSV

The unfortunate caveat is that there is no playoff data publicly visible, but the estimates should always be very close nonetheless. If playoff data is known, it could be later added as a manual json entry.
